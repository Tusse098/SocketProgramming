# SocketProgramming
SocketProgramming tests and fun

## A simple Server To Client networking exercise
A running server waiting for a simple connection from the client program.
When the client connects the server will simply send a "Hello World!" message which the client will recieve and then close.
SIMPLE!

### To Run
#### Server
cl /EHsc HelloWorldServer.c++
HelloWorldServer.exe

#### Client
cl /EHsc HelloWorldClient.c++
HelloWorldClient.exe


## Extras
There are also some extra practice code from smaller tests and exercises which can be ignored.
